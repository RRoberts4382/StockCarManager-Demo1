# Orange County Speedway references

The catalog uses the 0.375-mile Rougemont, North Carolina asphalt oval for track ID 28. [Orange County Speedway venue description](https://www.ocstrack.net/about)

## Restart zone estimate

The catalog stores the existing Stock Car Manager restart window explicitly. The model places the start 10% of a lap before the finish and the end 2% before the finish, about 60.35 m and 12.07 m respectively on the authored spline. The venue publishes race procedures, and the game stations remain an estimate for its modeled layout. [Orange County Speedway rules](https://www.ocstrack.net/rules)
